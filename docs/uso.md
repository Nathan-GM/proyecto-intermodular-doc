## Casos de uso
Esta aplicación esta pensada para los siguientes usos:

* Ver libros disponibles
* Obtener libros
* Crear reseñas

## Usuarios tipo
Encontraremos 3 tipos de usuarios:

* **Usuario invitado** -> Aquel que no tenga una cuenta y este mirando en la aplicación
* **Usuario registrado** -> Aquel usuario que SI tenga una cuenta registrada. A diferencia del no registrado este permite las reseñas por ejemplo.
* **Usuario administrador** -> Usuario que es capaz de modificar cosas en la base de datos. Aquí por ejemplo podrían entrar los encargados.
