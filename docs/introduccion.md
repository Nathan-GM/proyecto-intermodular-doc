# Introducción
Este apartado se hablará del objetivo de **El Librillo de Bolsillo** y que problema trata de resolver. 

## Objectivo del proyecto
El objetivo de este proyecto es ofrecer una aplicación que permita a usuarios
comprar diferentes libros y una manera sencilla a los encargados de gestionar la
aplicación.

## Problema que resuelve
Para los encargados suele ser complejo gestionar las aplicaciones de tienda y la 
base de datos de esta. Con este proyecto se ofrece una solución a esa complejidad
y permite a los encargados interactuar con la base de datos sin necesidad de tener conocimientos.
