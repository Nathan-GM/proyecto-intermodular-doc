# El Librillo de Bolsillo

El **Librillo de Bolsillo** se trata de una página web que permite vender libros a distintos usuarios.

## Tecnologias usadas.
Para este proyecto se han usado distintas tecnologías. Entre ellas se encuentran:

### Programación y diseño
* PHP y PHP MyAdmin.
* JavaScript
* HTML y CSS.
* MySQL

### Control de versiones y documentación
* **_Git_** para llevar el control de versiones.
* **_GitHub_** como gestor de repositorios web.
* **Markdown - ficheros .md** para crear la documentación
* **_GitHub Pages_** para mostrar la documentación del proyecto
